PROBLEM STATEMENT

In many rural and semi-urban areas, access to qualified medical professionals is limited. People often rely on unreliable internet searches or word-of-mouth to understand their symptoms, leading to delayed treatment or incorrect self-medication.

Can a rule-based AI system help a layperson identify a probable illness based on their symptoms and recommend a safe course of action — without needing internet access or a doctor immediately available?

WHAT THIS PROJECT BUILDS

MediBot is a rule-based Medical Symptom Diagnosis Expert System built using SWI-Prolog.

It demonstrates one of the foundational paradigms in Artificial Intelligence: Knowledge Representation and Rule-Based Inference — the same technology used in early AI systems like MYCIN (1970s) that pioneered medical AI.

WHY THIS IS CORE AIML

AIML Concept: Knowledge Representation
How This Project Demonstrates It:
Symptoms and diseases are stored as Prolog facts and rules.

AIML Concept: Rule-Based Inference
How This Project Demonstrates It:
Horn clauses implement IF-THEN diagnostic logic.

AIML Concept: Expert Systems
How This Project Demonstrates It:
The system mimics the reasoning of a medical expert.

AIML Concept: Logical Deduction
How This Project Demonstrates It:
Prolog's backtracking engine searches for valid diagnoses.

AIML Concept: Separation of Knowledge and Inference
How This Project Demonstrates It:
Knowledge Base files (.pl) are separate from the inference engine (main.pl).

SCOPE AND LIMITATIONS

• Covers 9 common conditions:
Cold, Flu, COVID-19, Strep Throat, Migraine, Gastroenteritis, Pneumonia, Allergic Reaction, and Dengue Fever.

• Uses a Yes/No symptom questionnaire containing 14 symptoms.

• The system is designed for educational purposes only and is not a substitute for real medical advice.

• The system does not handle multiple simultaneous diagnoses. The first matching rule is selected.

PROJECT OBJECTIVE

The main objective of MediBot is to demonstrate how Artificial Intelligence concepts such as knowledge representation, logical reasoning, rule-based inference, and expert system architecture can be implemented using Prolog.

The project provides a simple and transparent approach in which symptoms are collected from the user and matched against predefined rules to identify a probable medical condition and provide an appropriate action plan.

NOTE

MediBot is developed strictly for educational purposes as part of the Artificial Intelligence & Machine Learning course. It should not be used as a replacement for professional medical diagnosis, treatment, or advice.

"The goal of AI is not to replace human experts, but to make their expertise accessible to everyone."
